# QUALITY GATES

- Build: obrigatório
- Unit Tests: obrigatório
- Integration Tests: obrigatório
- Architecture Validation: obrigatório
- Code Review: obrigatório
- Security Checks: obrigatório
- Documentation: obrigatório
- Acceptance Criteria: obrigatório
- Knowledge Compliance: obrigatório
- SOLID (SRP, OCP, LSP, ISP, DIP): obrigatório

Nenhum Quality Gate crítico pode ficar pendente em PR aberto para `develop`, `hml` ou `main`.
