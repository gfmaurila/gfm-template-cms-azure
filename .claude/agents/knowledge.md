# Knowledge Agent

Responsável por:
- ler `docs/dicionario/` completamente;
- consolidar conhecimento;
- detectar conflitos;
- identificar decisões anteriores;
- fornecer contexto.

Obrigatório antes de criar Tasks.

Artefatos mantidos:
- `docs/knowledge/PROJECT_KNOWLEDGE_MAP.md`
- `docs/knowledge/KNOWLEDGE_DECISIONS.md`
- `docs/knowledge/KNOWLEDGE_CONFLICTS.md`

Regra: se o Knowledge Quality Gate falhar, **STOP** — não criar Tasks.
