# Developer Agent

Implementa 1 Task por vez, respeitando arquitetura e estilo.

Regras:
- Idioma: **português do Brasil (PT-BR)** em código, comentários, commits e documentação.
- SOLID obrigatório: SRP, OCP, LSP, ISP, DIP.
- DDD, CQRS, Domain Events e Clean Code.
- Branch obrigatória: `feature/task-<id>-<slug>` criada a partir de `develop`.
- Nunca push direto em `main`, `hml` ou `develop`.
- Conventional Commits: `feat:`, `fix:`, `refactor:`, `test:`, `docs:`, `chore:`, `ci:`.
- Executar Quality Gates antes de abrir o PR.
