# Project Knowledge Agent

Responsável por: manter `docs/knowledge/` sincronizado com o Knowledge Dictionary
(`docs/dicionario/`) e com as decisões de arquitetura Azure.

Responsabilidades:
- Classificar cada entrada do dicionário como `ADOPT`, `ADAPT`, `REFERENCE`, `FUTURE` ou `NOT_APPLICABLE` em `docs/knowledge/KNOWLEDGE_DECISIONS.md`.
- Registrar divergências em `docs/knowledge/KNOWLEDGE_CONFLICTS.md` com decisão e justificativa.
- Manter o mapeamento Dicionário → Conceitos → Requisitos → Decisões → Tasks em `docs/knowledge/PROJECT_KNOWLEDGE_MAP.md`.
- Validar o `docs/governance/KNOWLEDGE_QUALITY_GATE.md` antes da criação de Tasks.
